# Interactive prototype map

The running `app/page.tsx` is the interactive wireframe. It covers the principal MVP journeys below.

| Screen / journey | Prototype section or interaction | Production extension |
|---|---|---|
| Public home | Hero, mission, trust/compliance badges | CMS-managed regional content and SEO pages |
| Product catalog | Live Market cards | Filterable API catalog with origin, grade, MOQ, packaging and moisture data |
| Buyer RFQ | Sourcing Engine + Global Trade Portal modal | Authenticated RFQ, quote comparison, approval and order workflow |
| Farmer onboarding | Farmer Portal modal | Offline-first PWA forms, agent assignments and evidence upload |
| Quality standards | Farm-to-Market operating system + escrow workflow | Lot QC checklists, inspection reports and certificate vault |
| Logistics | Cold-chain section | Shipment map, sensor events, exception handling and proof of delivery |

## Suggested Figma frames

1. Mobile home and catalog browse.
2. Buyer RFQ builder and quote acceptance.
3. Farmer/agent harvest registration offline state and synced state.
4. Buyer order tracking with shipment timeline.
5. Admin quality review queue.
